# Smile Dental Care Website

## Project Overview
Smile Dental Care is a personal website project created using an AI-powered website builder. The project explores how AI-assisted tools can help create a digital presence for a dental clinic.

## Objective
To present clinic information through a clear, accessible, and user-friendly website concept.

## Tools Used
- AI-powered website builder
- GitHub for project documentation
